See [the executed notebook](../../notebooks/ASyn_tICA_MSM_Review.ipynb) for reproducible calculations and plots.

The comparison uses C-alpha pair distances, local writhe descriptors, and sine/cosine pairs of C-alpha pseudo-dihedrals. The accompanying feature cache contains coordinates, writhe features, and segment definitions; writhe features were computed with writhe-tools 0.0.0.30, using length-three segments and excluding pairs sharing endpoints. The notebook downloads this cache automatically in Colab.

There are 5,555 saved frames. Frame spacing is inferred as 200 microseconds / 5,555 from the stated trajectory duration, not independently verified from simulation metadata. All reported physical lag times depend on that assumption.

## Findings

Full-trajectory slow modes look substantially more persistent than modes tested across trajectory halves. This limits their interpretation as reproducible slow processes. The notebook includes structural observables, representative conformations, lag dependence, and forward/reverse half-trajectory tests.

A two-state model based on periodic pseudo-dihedral features is included as an exploratory example. The full-data fit has highly unequal equilibrium populations (approximately 98.35% and 1.65%) and a relaxation time of approximately 1.24 microseconds. Its partition differs substantially from the training-half partition. A small held-out CK error for the training-half model does not validate the full-data refit or establish metastability. Rapidly mixing models can also have small CK errors.

Model selection reused the held-out half, so it is a diagnostic comparison rather than an independent final validation. Further independent trajectories and stable state assignments would be needed for stronger kinetic claims.
